# Wisdom Science Academy – Official Website 🌟

A modern, responsive, and content-rich website built for **Wisdom Science Academy**, designed to showcase academic excellence, admissions details, infrastructure, and student-focused learning using **Bootstrap 5**.

---

## 📌 Project Overview

This website represents an educational coaching institute offering CBSE & State Board coaching for **Std. 7th to 12th** students.  
It focuses on clarity, trust, admissions promotion, and user-friendly navigation across all devices.

---

## 🚀 Features

- Fully responsive design (Mobile, Tablet, Desktop)
- Bootstrap 5.3 based layout
- Offcanvas mobile navigation menu
- Smooth scrolling for internal links
- Structured sections for academics, admissions & contact
- Font Awesome icons
- Google Fonts (Poppins)
- Clean UI with modern cards & CTAs

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- Bootstrap 5.3.2  
- JavaScript (Vanilla)  
- Font Awesome 6  
- Google Fonts

3. Ensure the images folder path is correct
4. No backend required
